# M1 VNext design

The baseline is retained unchanged. VNext wraps only the experimental selector. Existing residual feature/shelf/candidate machinery produces bounded metadata-bearing candidates. A signature is filter type plus frequency bucket derived from configured min/max log span and feature-region count, independent of IDs and fine parameters. Admission takes first unseen residual region, mutation family and signature before normal quality order. Beam retention takes best quality representative per signature before standard comparator fill. On a stalled generation, VNext evaluates bounded single-filter removals using existing delivered metrics, then replaces least-damaging victims with bounded unresolved-region candidates and jointly polishes. Existing rescue, pair-add, cap-swap and cleanup remain intact. Traces carry diversity and replacement counters plus final-improvement phase.
